Valheim Block Planner

Drop a character file to see what you can block and parry, plus your skills, gear and stats in plain language. Read-only: the file is read in this tab, never uploaded and never changed.

Character on Steam Cloud? Move it to local first
  1. Launch Valheim and go to the character select screen.
  2. Click Manage Saves.
  3. Open the Characters tab.
  4. Pick the character with the cloud icon next to it.
  5. Click Move to Local.
  6. Exit the game. The character is now in %USERPROFILE%\AppData\LocalLow\IronGate\Valheim\characters_local

Or skip this: Steam keeps cloud saves in Steam\userdata\<your Steam ID>\892970\remote\characters, and you can drop the .fch from there too.
